In PHP, declare(strict_types=1) must be the very first statement in a file — even a blank line before <?php will trigger a fatal error. Once enabled, passing "5" to a function typed int $qty throws a TypeError instead of silently coercing to 5.

A few related notes:

  • array_column() works on arrays of arrays and arrays of objects.
  • The null-safe operator ?-> short-circuits the whole chain.
  • Prefer str_contains($haystack, $needle) over strpos(...) !== false.

See strict typing and the RFC that introduced it for the original rationale.
